# 🎓 Student Resources Hub

### One Platform for All Your Academic Resources

Student Resources Hub is a web-based platform designed to help students access academic resources in one place. Students can explore notes, previous year question papers, syllabus, e-books and AI-powered study tools.

🌐 **Live Website:** https://student-resources-1vnzb3d3d-student-resource-hub1.vercel.app/login

💻 **GitHub Repository:** https://github.com/kumarabhiraj05981-dot/student-resources-hub

---

## 🚀 About the Project

Student Resources Hub makes learning easier by providing students with a centralized platform for academic materials.

Instead of searching across multiple websites and platforms, students can access their study materials from one place.

The platform also provides AI-powered question paper generation and other study-related features to support exam preparation.

---

- AI Study Assistant.

- User Registration and Login.
- User Dashboard.
- Bookmark important resources.
- Manage user profile.
- Download academic materials.
- Notifications.

### 🛡️ Admin Features
- Admin Dashboard.
- Upload academic resources.
- Manage Notes, PYQs, Syllabus and E-Books.
- Edit and delete resources.
- Manage academic content.
- View platform analytics.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/kumarabhiraj05981-dot/student-resources-hub.git
```

### 2. Open Project Folder

```bash
cd student-resources-hub
```

### 3. Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
GEMINI_API_KEY=your_gemini_api_key
```

Start the backend:

```bash
npm run dev
```

### 4. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
```

Create a `.env` file inside the frontend folder:

```env
VITE_API_URL=http://localhost:5000/api
```

Start the frontend:

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5173
```

- Never expose API keys or database credentials.
- Use environment variables in deployment platforms.
- Keep JWT secrets and Cloudinary credentials private.
